- GPT-5.1 and newer now edit files with `apply_patch` (OpenAI's V4A patch format) in the Python REPL: the whole patch is checked before any write, and a failed write undoes every change. Set `editFormat` per model in `models.json`, or `"applyPatch": "off"` in `settings.json` to keep `edit` everywhere; the format follows `/model` switches, and the TUI colours patch literals in python cells.
