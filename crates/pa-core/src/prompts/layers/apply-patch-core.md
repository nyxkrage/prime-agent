- `apply_patch(patch: str) -> list[dict]`: the primary method for editing files. async; takes one V4A patch (`*** Begin Patch` ... `*** End Patch` around `*** Update File: <path>` sections with `@@` hunks of ` `/`-`/`+` lines, plus `*** Add File:`, `*** Delete File:`, `*** Move to:`); validates the whole patch before writing anything and raises `apply_patch.PatchError` (naming the file, hunk, and reason) with no file changed if any part fails; then writes each hunk through `edit.run`; returns one `{"path", "operation", "hunks", "move_to"}` summary per file
- `edit.run(path: str, old_str: str, new_str: str) -> str`: one exact replacement, which `apply_patch` writes through. async, exact-unique-match; the `edit` module is callable with the same arguments (`await edit(path=..., old_str=..., new_str=...)`)
