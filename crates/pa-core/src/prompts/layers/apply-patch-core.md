- `apply_patch(patch: str) -> list[dict]`: the primary method for editing files. async; takes one V4A patch in the OpenAI Codex `apply_patch` format (`*** Begin Patch` ... `*** End Patch` around `*** Update File: <path>` sections, optionally followed by `*** Move to: <path>`, with `@@` or `@@ <line>` hunks of ` `/`-`/`+` lines; `*** Add File: <path>` with `+` lines; `*** Delete File: <path>`); pass it as a raw string (`r'''...'''`) so backslashes reach the files unchanged; checks the whole patch first and, if any part would fail, raises `apply_patch.PatchError` (naming the file, the hunk where relevant, and the reason) with no file changed; otherwise writes the changes (existing files in place, like `edit`), undoes every change already made if a write fails, and shows each changed hunk's diff like `edit`; returns one `{"path", "operation", "hunks", "move_to"}` summary per file
- `edit.run(path: str, old_str: str, new_str: str) -> str`: one exact replacement, for a change a patch does not fit. async, exact-unique-match; the `edit` module is callable with the same arguments (`await edit(path=..., old_str=..., new_str=...)`)
