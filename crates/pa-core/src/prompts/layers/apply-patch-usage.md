- Edits of existing files must be performed using `apply_patch` with one V4A patch per logical change, written as a raw string: in a plain `'''...'''` literal Python interprets backslashes, so a `\n`, `\t`, or `\d` in the patched code would reach the file as a different character. For example, a cell `await apply_patch(r'''*** Begin Patch`, then the lines `*** Update File: pkg/file.py`, `@@ def main():`, `-    print("hi")`, `+    print("hello")`, and `*** End Patch''')`; the context and `-` lines must match the file (only whitespace may differ), so the agent inspects the file first; if the patch contains triple single quotes ('''), the agent should wrap it in `r"""..."""` instead.
