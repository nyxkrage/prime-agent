- Edits of existing files must be performed using `apply_patch` with one V4A patch per logical change, for example `await apply_patch('''*** Begin Patch\n*** Update File: pkg/file.py\n@@ def main():\n-    print("hi")\n+    print("hello")\n*** End Patch''')`; the context and `-` lines must match the file (only whitespace may differ), so the agent inspects the file first; if the patch contains triple single quotes ('''), the agent should wrap it in triple double quotes instead.
